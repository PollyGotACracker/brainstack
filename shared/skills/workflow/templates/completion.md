# 완료 보고

- director가 최종 상태 기록을 확인한 뒤 작업 결과를 사용자에게 보고할 때 사용한다.
- 출처는 사용자 요구 핵심 요약으로 적는다.
- 짧은 값 비교는 표, 문장 근거는 목록으로 적는다.

```markdown
# 완료 보고: <작업 이름>

| 요구사항   | 판정                     |
| ---------- | ------------------------ |
| <요구사항> | <PASS \| FAIL \| 미측정> |

- <요구사항>: <근거 위치·명령 결과>
- 결과물: <경로>
- 문서 갱신: <경로 | "검색어와 일치 없음" | 해당 없음>
- 남은 문제: <항목 | 없음>
```

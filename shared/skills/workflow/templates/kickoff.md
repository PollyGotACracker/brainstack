# 착수 보고

- director가 사전 질문의 답을 받은 뒤 착수 승인을 요청할 때 사용한다.
- 출처는 사용자 요구 핵심 요약으로 적는다.
- 짧은 값 비교는 표, 문장 근거는 목록으로 적는다.

```markdown
# 착수 보고: <작업 이름>

- 목적: <목적>
- 상태 문서: <경로 | 승인 후 생성>

## 요구사항

- <요구사항>

## 유지 항목

- <항목>

## 기준 자료 특징

- <기준 자료>: <관찰한 특징> (출처: <`파일:행` | 링크>)

## 완료 기준

- <확인 대상·조건·기대 결과>

## 확정 결정·제약

- <내용> (출처: <사용자 요구 핵심 요약 | `파일:행`>)

## 조사 계획

- 외부 조사: <필요 | 불필요> (이유: <1문장>)
- 조사 질문: <질문>
- 판정 기준: <기준>
- 제외 범위: <범위>

## 진행 순서

1. <단계> (담당: <역할>)

## 재판단 조건

- <조건>

## 승인 요청

- 승인 대상: <위 내용으로 착수>
```

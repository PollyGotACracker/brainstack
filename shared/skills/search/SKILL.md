# 조사 보고

- 조사 순서는 상위 지침의 조사 절차 기준을 적용한다.
- 프로젝트 지침에 조사 순서가 정해진 경우 해당 기준을 적용한다.

## 검색 결과 요약

웹 검색 시 응답 최하단에 아래 형식으로 요약한다.

### 표시 값

- 조사 결과를 `[확인 완료]`, `[자료 부족]`, `[미조사]` 중 하나로 표시한다.
- 출처마다 실제 열람 범위를 표시한다.
  표시 값은 `전문 열람`, `본문 열람`, `발췌만 확인`, `미열람` 중 하나이다.

### 보고 형식

- 추가 조사 후에도 근거가 부족한 경우 `[자료 부족]`에 확인 범위·사유를 기재한다.
  `[미조사]`에는 조사 생략 사유를 기재한다.
  보고는 아래 형식을 적용한다.

```markdown
## 검색 결과 요약

- <항목> [확인 완료]
  - <출처> `<열람 수준>`
- <항목> [자료 부족]
  - <출처> `<열람 수준>`
  - 확인 범위: <범위와 부족 사유>
- <항목> [미조사]
  - 사유: <사유>
```

## 도구 권고

### 조사 지표

- 도구 권고 시 다음 지표와 검증 자료를 조사한다.
  - 채택 규모
  - 커뮤니티 활동
  - 마지막 갱신
  - 이슈 종료 빈도
  - deprecated 여부
- 각 지표의 출처와 확인 결과를 기록한다.

### 권고 기준

- 권고 후보는 사용 목적에 필요한 기능·호환성·제약이 확인된 도구로 한정한다.
  나머지 도구는 미확인으로 구분한다.
- 대중성·유지보수 지표의 확인값을 제시한다.
  수치 임계값은 사용자가 정한 경우에만 판정에 적용한다.

# 계획 승인 요청

- director가 조사 결과에 대한 사용자 판단 뒤 실행 계획의 승인을 요청할 때 사용한다.
- 출처는 사용자 요구 핵심 요약으로 적는다.
- 짧은 값 비교는 표, 문장 근거는 목록으로 적는다.

```markdown
# 계획 승인 요청: <작업 이름>

- 상태 문서: <경로>
- 계획 원문: <경로 | 아래 본문>

## 변경 요약

- <대상>: <변경 내용>

## 사용처 검색

- <검색어>: <결과와 포함·제외 근거>

## 문서 갱신 대상

- <문서 경로 | "검색어와 일치 없음">

## 승인 요청

- 승인 대상: <행동과 영향 범위>
- 별도 승인: <이동·삭제·외부 링크 | 없음>
```

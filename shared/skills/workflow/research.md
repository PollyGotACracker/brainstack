# 설계

- 목적이 설계로 확정된 직후 이 파일을 읽는다.

## 사전 질문 체크리스트

- 검토 대상, 목표, 제약, 판단 기준을 확인한다.
- 구현 시 유지할 동작, 완료 기준, 기존 클라이언트 영향을 확인한다.
  이유는 설계 뒤 구현에서 같은 질문의 반복을 막기 위해서이다.

## 단계

1. director가 초안으로 쟁점, 후보, 비교 기준을 작성한다.
2. 반증 대상은 후보별 주장의 외부 근거와 누락된 대안이다.
3. 조사 결과 보고 끝에 결정·보류·기각·추가 조사 선택지를 둔다.
4. documenter가 설계 양식으로 설계 기록을 작성한다.
5. 완료 보고 후 구현으로 이어지면 `implement.md`를 읽는다.

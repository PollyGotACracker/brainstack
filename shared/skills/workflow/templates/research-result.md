# 조사 결과 보고

- director가 반증 결과를 대조한 뒤 사용자 판단을 요청할 때 사용한다.
- 출처는 사용자 요구 핵심 요약으로 적는다.
- 짧은 값 비교는 표, 문장 근거는 목록으로 적는다.

```markdown
# 조사 결과: <작업 이름>

## 확인한 사실

- <사실> (출처: <`파일:행` | 링크>, 유형: <공식 | 사례 | 기타>)

## 반증 결과

| 주장        | 판정                     |
| ----------- | ------------------------ |
| <주장 요약> | <지지 \| 반증 \| 미확인> |

- <주장 요약>: <근거와 출처>

## director 판단

- <결론> [추론]
  <근거와 과정>

## 미확인

- <항목>: <사유>

## 다음 단계

- <목적 파일의 선택지 또는 사용자 판단 요청>
```

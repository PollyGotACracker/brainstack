# 사전 질문

- director가 작업 요청을 받고 착수 보고 전에 사용자에게 질문할 때 사용한다.
- 출처는 사용자 요구 핵심 요약으로 적는다.
- 짧은 값 비교는 표, 문장 근거는 목록으로 적는다.

```markdown
# 사전 질문: <작업 이름>

- 목적: <설계 | 구현 | 디버깅 | 지침·문서>

## 체크리스트

- <항목>: <값> (<확인 | 추정>, 출처: <`파일:행` | 사용자 요구 핵심 요약>)
- <항목>: 미확인 → 질문 <번호>

## director가 정한 항목

- <항목>: <결정> (근거: <출처>)

## 질문

1. <질문>
   - 선택지: <A: 결과 | B: 결과>
   - director 판단: <권장안과 근거>
   - 반대 근거: <내용 | "찾지 못함"과 확인 범위>
   - 답이 바꾸는 것: <1문장>
   - 수집 방법: <명령 | 없음>
```

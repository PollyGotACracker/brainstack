# 조사 보고

## 조사 절차

1. 조사 전에 요청과 제공 자료를 대조해 필수 정보의 누락 여부를 확인한다.
   누락 항목은 항목과 필요한 이유를 적어 질문한다.
2. 최초 웹 검색은 사용자가 질문하는 대상, 사용자의 상황, 달성하고자 하는 목표 자체를 키워드로 한다.
3. 사용자가 자료 유형을 지정하면 그 유형의 자료를 우선한다.
   지정이 없으면 요청한 대상·버전에 맞는 공식 원문을 우선한다.
   자료마다 유형(공식 문서·사용자 사례·기타)을 출처와 함께 적는다.
   게시·갱신 시점을 확인해 해당 요청에 적용할 수 있는 자료인지 대조한다.
4. 자료가 상충하면 원본을 열어 갱신 시점을 확인한다.
5. 확인 결과가 없는 항목은 미확인으로 표시한다.

## 검색 결과 요약

웹 검색 시 응답 최하단에 아래 형식으로 요약한다.

### 표시 값

- 조사 결과를 `[확인 완료]`, `[자료 부족]`, `[미조사]` 중 하나로 표시한다.
- 출처마다 실제 열람 범위를 표시한다.
  표시 값은 `전문 열람`, `본문 열람`, `발췌만 확인`, `미열람` 중 하나이다.

### 보고 형식

- 추가 조사 후에도 근거가 부족한 경우 `[자료 부족]`에 확인 범위·사유를 기재한다.
  `[미조사]`에는 조사 생략 사유를 기재한다.
  보고는 아래 형식을 적용한다.

```markdown
## 검색 결과 요약

- <항목> [확인 완료]
  - <출처> `<열람 수준>`
- <항목> [자료 부족]
  - <출처> `<열람 수준>`
  - 확인 범위: <범위와 부족 사유>
- <항목> [미조사]
  - 사유: <사유>
```

## 도구 권고

### 조사 지표

- 도구 권고 시 다음 지표와 검증 자료를 조사한다.
  - 채택 규모
  - 커뮤니티 활동
  - 마지막 갱신
  - 이슈 종료 빈도
  - deprecated 여부
- 각 지표의 출처와 확인 결과를 기록한다.

### 권고 기준

- 권고 후보는 사용 목적에 필요한 기능·호환성·제약이 확인된 도구로 한정한다.
  나머지 도구는 미확인으로 구분한다.
- 대중성·유지보수 지표의 확인값을 제시한다.
  수치 임계값은 사용자가 정한 경우에만 판정에 적용한다.

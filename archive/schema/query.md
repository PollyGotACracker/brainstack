# query

이 문서는 위키 검색을 통한 인용 포함 답변 작성 절차이다.

## 입력

- `QUESTION`은 사용자 질문이다.

## 절차

1. `QUESTION`에서 핵심어를 추출한다.
2. 핵심어로 `wiki/` 폴더를 검색한다.
3. 검색 결과 상위 페이지를 확인한다.
4. 인용을 포함한 답변을 종합한다.
5. 위키에 없는 내용이나 새 인사이트를 발견하면 사용자에게 새 페이지를 제안한다.
6. 필요한 경우 분석 결과로 새 페이지를 작성한다.

## 진행 방식

1. 질문의 모든 항목에 답변한다.
2. 파일 작성 전 내용을 우선 제안한다.

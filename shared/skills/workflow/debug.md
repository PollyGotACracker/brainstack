# 디버깅

- 목적이 디버깅으로 확정된 직후 이 파일을 읽는다.

## 사전 질문 체크리스트

- 실행 위치와 경로, 실행 명령과 인자를 확인한다.
- 로그 원문을 확인하고, 로그가 없으면 director가 수집 명령을 제시한다.
- 기대 동작과 실제 동작을 확인한다.
- 발생 조건과 재현 절차, 최근 변경을 확인한다.

## 단계

1. 로그나 재현 결과를 확보한 뒤 director가 초안으로 원인 가설을 작성한다.
   코드만으로 찾은 원인은 미확인 후보로 표시한다.
2. 반증 대상은 가설과 로그·재현 결과의 일치이다.
3. 조사 결과 보고 끝에 종료·수정 진행·추가 조사 선택지를 둔다.
4. 수정 진행이면 `implement.md`의 4단계부터 진행한다.
   reviewer는 재현 절차로 증상 해소를 확인한다.
